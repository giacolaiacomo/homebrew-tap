# giacolaiacomo/tap

Homebrew formulae by [@giacolaiacomo](https://github.com/giacolaiacomo).

```sh
brew install giacolaiacomo/tap/burny
brew services start burny

brew install giacolaiacomo/tap/glancy
brew services start glancy
```

| Formula | What it is |
|---|---|
| [burny](https://github.com/giacolaiacomo/burny) | Menu bar app showing your Claude Code and Codex plan limits: 0 tokens, local only, about 13 MB of RAM. |
| [glancy](https://github.com/giacolaiacomo/glancy) | Notch app: Claude Code agents, next meeting with Join, now playing, clipboard history and window tiling in the MacBook notch. About 19 MB of RAM, local only. |

Formulae build from source on your Mac.
